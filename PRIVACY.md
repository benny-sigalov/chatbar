# Privacy Policy

Last updated: May 21, 2026

ChatBar is a browser extension that lets users attach screenshots of the currently visible browser tab to ChatGPT messages.

## Data ChatBar Handles

ChatBar may handle:

- A screenshot of the currently visible browser tab when the user explicitly requests it.
- The active tab URL and title, used only to show whether the current page can be captured and to display a short source label.
- The current ChatGPT page URL, used to restore the side panel path during the current browser session.

## What ChatBar Does Not Do

ChatBar does not:

- Run a backend server.
- Send screenshots or page data to a ChatBar-controlled server.
- Store screenshots permanently.
- Keep screenshot history.
- Sell user data.
- Use analytics.
- Collect usage statistics, telemetry, or tracking information.
- Collect ChatGPT messages for ChatBar-controlled storage.
- Capture pages silently or continuously.

## Screenshot Uploads

ChatBar captures the visible tab in your browser and pastes the screenshot directly into the ChatGPT composer, similar to taking a screenshot yourself and attaching or pasting it manually. ChatBar does not route screenshots through a ChatBar server.

When the screenshot is attached to ChatGPT, ChatGPT handles the upload and processing of that screenshot. OpenAI's own terms and privacy policy apply to ChatGPT and uploaded content.

OpenAI policies are available at:

- https://openai.com/policies/
- https://openai.com/policies/privacy-policy/

## Permissions

ChatBar uses broad host access (`<all_urls>`) so the user can capture the currently visible browser tab from the Chrome side panel. This access is used only for user-initiated screenshot capture and capturability checks.

ChatBar uses ChatGPT host access so it can add the ChatBar toolbar to ChatGPT pages.
