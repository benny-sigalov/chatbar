# Publishing Checklist

This checklist is for preparing ChatBar for GitHub and the Chrome Web Store.

## GitHub Release Prep

- [ ] Confirm `README.md` is accurate.
- [ ] Confirm `PRIVACY.md` is accurate.
- [ ] Confirm `LEGAL.md` is accurate.
- [ ] Confirm `LICENSE` is correct for the intended release.
- [ ] Run `yarn check`.
- [ ] Run `yarn package`.
- [ ] Review the generated zip in `release/`.
- [ ] Create screenshots or a short demo GIF for the README.
- [ ] Tag the release.

## Chrome Web Store Prep

- [ ] Register or open the Chrome Web Store Developer Dashboard.
- [ ] Create the item.
- [ ] Upload the zip generated by `yarn package`.
- [ ] Complete the store listing.
- [ ] Complete the Privacy tab.
- [ ] Provide a public privacy policy URL.
- [ ] Explain why `<all_urls>` is needed.
- [ ] Explain why ChatGPT host access is needed.
- [ ] Add screenshots showing:
    - ChatGPT in the side panel.
    - The ChatBar toolbar.
    - Manual screenshot attach.
    - Auto screenshot toggle.
- [ ] Test the submitted build from a clean Chrome profile.

## Suggested Single Purpose

ChatBar lets users attach a screenshot of their current visible browser tab to a ChatGPT message from the Chrome side panel.

## Permission Justifications

`sidePanel`:

Allows ChatBar to open ChatGPT in Chrome's side panel.

`activeTab`:

Used for Chrome extension compatibility with user-invoked tab access.

`<all_urls>`:

Required because screenshot capture is initiated from the side panel and must work on the user's currently visible tab. ChatBar does not capture continuously and does not store screenshot history.

`https://chatgpt.com/*` and `https://chat.openai.com/*`:

Required to add the ChatBar toolbar to ChatGPT pages.

## Privacy Practices Draft

Data handled:

- Website content: screenshots of the active visible tab, only after user action.
- Website metadata: active tab URL/title for source display and capturability checks.

Data not collected by ChatBar:

- Analytics
- Browsing history
- ChatGPT conversation history
- Screenshot history
- User account data

Data sharing:

- ChatBar itself does not send data to a ChatBar server.
- Screenshots attached to ChatGPT are uploaded to OpenAI by ChatGPT.

## Store Listing Draft

Short description:

Attach screenshots of your current browser tab to ChatGPT from the side panel.

Long description:

ChatBar opens ChatGPT in Chrome's side panel and adds a small toolbar below the composer. Click Screenshot now to capture the visible browser tab and attach it to your current ChatGPT message. Turn on Auto screenshot to capture and attach the current page before sending.

ChatBar is user-controlled: screenshots are captured only when you click Screenshot now or send while Auto screenshot is enabled. ChatBar does not store screenshot history, does not run a backend server, and does not use analytics.

ChatBar is not affiliated with OpenAI.
