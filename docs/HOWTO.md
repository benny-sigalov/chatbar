# How To Use ChatBar

## Open ChatBar

1. Install or load the extension.
2. Click the ChatBar extension icon.
3. ChatGPT opens in Chrome's side panel.

## Attach A Screenshot Manually

1. Navigate the main browser tab to the page you want ChatGPT to see.
2. In ChatGPT's side panel, type your message.
3. Click `Screenshot now`.
4. ChatBar captures the current visible tab and attaches it to the ChatGPT composer.
5. Review the attachment.
6. Send your message.

## Auto Screenshot

1. Turn on `Auto screenshot`.
2. Type your message.
3. Press Enter or click ChatGPT's Send button.
4. ChatBar captures and attaches the current visible tab before sending.

If the active page cannot be captured, ChatBar does not interrupt sending.

## Pages Chrome Does Not Allow Capturing

Chrome does not allow extensions to capture some protected pages, including:

- `chrome://` pages
- Chrome extension pages
- Chrome Web Store pages
- DevTools pages
- Some browser internal pages

When this happens, ChatBar disables screenshot capture and shows a short reason.
